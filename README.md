# 企业知识治理与智能问答实践

本目录用于整理书稿。当前名称为工作名称，不代表最终书名。

## 写作定位

从企业实际使用知识的方式出发，讨论知识治理、业务场景、检索依据和回答责任之间的关系。重点不是介绍平台按钮或罗列技术，而是讲清楚：哪些资料值得用于问答，系统应该回答什么，怎样让答案有依据，以及知识如何持续维护。

面向参与企业知识库建设的业务负责人、知识维护人员、产品人员和技术实施人员。以通俗中文解释问题，保留必要的边界和判断条件，不把个别平台的限制写成普遍规律。
