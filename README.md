# 企业知识治理与智能问答实践

本书面向正在规划或建设企业知识问答系统的团队，围绕知识资料治理、业务场景设计、检索与证据、可信回答、风险控制和持续运营，梳理从知识进入系统到答案参与业务的完整实践路径。

## 本书内容

企业知识问答不只是把文档接入模型、再配置一个检索接口。本书从企业实际使用知识的方式出发，讨论如何判断资料是否适合进入问答、如何界定系统的业务职责、如何让回答有据可查，以及如何建立持续更新和效果评估机制。

全书依次介绍资料准入与知识治理、场景和知识库边界、文档与元数据管理、多模态解析、混合检索与证据筛选、答案引用与冲突处理、运行风险、智能体协同、评测监控、知识更新，以及工具调用中的授权和结果核验。

## 适合读者

适合参与企业知识库或智能问答项目的业务负责人、知识维护人员、产品经理、架构师和技术实施人员。书中尽量用通俗中文解释关键概念，同时说明适用条件、责任边界和需要人工确认的环节。

## 阅读说明

可按目录顺序阅读，建立从知识治理到业务应用的整体认识；也可根据项目阶段，选择资料准入、场景设计、检索评测或持续运营等章节查阅。书中的案例、场景定义卡、字段样例、检索流程和图示用于说明实践方法，不代表任何特定企业制度、平台能力或实际运行结果；落地时应结合组织自身的制度、数据和权限要求进行验证。
